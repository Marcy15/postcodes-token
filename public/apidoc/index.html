Postcodes REST API

Magyarországi települések, irányítószámok és megyék keresése, szűrése és karbantartása. Az adatok a mellékelt SQL-dumpból származnak.

Alap URL: http://127.0.0.1:8000/api · Nyilvános GET lekérdezések, minden adatmódosításhoz token szükséges.

Hitelesítés

Hozz létre egy admint a php artisan postcodes:create-admin admin@pelda.hu paranccsal, majd küldj POST kérést az /api/auth/login címre. A kapott token értékét használd az alábbi fejlécben:

Authorization: Bearer SAJAT_TOKEN
Accept: application/json
Content-Type: application/json

A token érvényessége 7 nap, a kijelentkezés visszavonja. A GET lekérdezésekhez nem kell token.
